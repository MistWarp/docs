# Wrapping up

That is the core of custom extension development. From here, the reference pages go deeper into each part of the API surface:

- [Scratch object API](/api-reference/extension-api): the full `Scratch` object, block utility, and permission APIs.
- [VM API](/api-reference/vm-api): the runtime, targets, threads, and events.
- [Renderer API](/api-reference/renderer-api): drawing skins and drawables directly.
- [Audio API](/api-reference/audio-api): the audio engine, sound players, and effects.
- [Utility APIs](/api-reference/utilities): `Scratch.Cast` and related helpers in detail.

If you need native-speed blocks, the [compiled extensions](/building-extensions/compiled/overview) section shows how to generate JavaScript directly through MistWarp's compiler.

## Getting help and contributing

You can browse the MistWarp extension gallery, and find its submission instructions, at [extensions.mistium.com](https://extensions.mistium.com).
