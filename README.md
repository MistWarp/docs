# MistWarp docs

The documentation for [MistWarp](https://mistwarp.org/), published at
https://mistwarp.org/docs/ and in the editor's Help window.

Found a mistake? Use "Edit this page" at the bottom of any page, or
[open an issue](https://github.com/MistWarp/docs/issues/new).

```bash
npm ci
npm start        # dev server, without search
npm run build    # full build with the search index
npm run check    # check that inbound links still resolve
```

See [AGENTS.md](AGENTS.md) for how the site is structured and deployed.
